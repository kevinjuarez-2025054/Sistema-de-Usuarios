# Sistema de Gestion de Usuarios

## Descripción

Este proyecto consiste en desarrollar una jerarquía de clases que simule un sistema de gestión de usuarios utilizando los principios de la Programación Orientada a Objetos (POO). El sistema permitirá administrar diferentes tipos de usuarios, como clientes y administradores, mediante herencia y reutilización de código.

## Objetivos

* Implementar una jerarquía de clases para representar distintos tipos de usuarios.
* Aplicar conceptos de herencia, encapsulamiento y polimorfismo.
* Desarrollar métodos para registrar usuarios en el sistema.
* Permitir la búsqueda de usuarios registrados.
* Mostrar la información de clientes y administradores de manera organizada.
* Funcionalidades
* Registro de clientes.
* Registro de administradores.
* Búsqueda de usuarios por un criterio definido (por ejemplo, ID o nombre).
* Visualización de la información de los usuarios registrados.
* Organización de las clases mediante una estructura jerárquica.
